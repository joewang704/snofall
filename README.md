# East Coast Snowfall Tracker


A simple HTML app that displays forecasted snowfall (in feet) for East Coast resorts using the [NWS API](https://api.weather.gov/).


**Live at:** [https://joewang704.github.io/snofall/](https://joewang704.github.io/snofall/)


## Features
- Lists all East Coast resorts (CT, MA, NH, VT, ME)
- Fetches snowfall forecast from NWS API
- Select any day within the next 7 days
